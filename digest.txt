# GridSense - Team 3

EV charging and load-management demonstration using simulated sensors, MQTT,
Node-RED, SQLite, five ML models and actuator feedback.

For the configured **public internet MQTT broker**, follow [CLOUD_MQTT.md](CLOUD_MQTT.md).
On the project laptop run `./start.ps1 -PublicBroker`; on the sensor laptop run
`python simulator.py --public-broker`. Copy the four sensor Python files **plus
`mqtt-public.json`** to the sensor laptop. This uses `broker.emqx.io:8883` with
verified TLS and project-specific topics. No account or password is required.
The LAN setup below remains available as an alternative.

## Architecture

The implementation follows the branching diagram in `refererncesss.png`:

```text
Sensor laptop: Python sensor/plant simulator
    -> ev/telemetry -> Project laptop: Aedes MQTT broker -> Node-RED
        -> live dashboard
        -> SQLite commit -> database read -> ML/evaluation -> decision
            -> ev/actuator -> same MQTT broker -> sensor laptop actuator
                -> ev/ack -> MQTT -> Node-RED -> SQLite control metrics
```

The live dashboard and database are parallel outputs. Analytics reads committed
records and does not depend on an open browser. The actuator runs inside the sensor
process; do not run `actuator.py` separately. Run only one live simulator per station.

## Install on the project laptop

Install Python 3.10+ and Node.js 20 or later. In the extracted `GridSense` folder:

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements-tested.txt
npm.cmd ci --prefix node-red
```

`requirements-tested.txt` records the Python versions used for the included models;
`requirements-station.txt` provides supported dependency ranges. If the exact tested
versions are unavailable for your Python/platform, install the ranged requirements
and retrain locally before using the model files. Temporarily rename `artifacts/bundle.pkl`
to `bundle.pkl.saved` before starting the service if a model-version mismatch prevents
startup; training creates a new compatible bundle. On Linux/macOS use
`.venv/bin/python`, `npm` and `source .venv/bin/activate`.

Replace the example IP with the project laptop's address. Use `python3` where needed.

Open on the project laptop:

"""Actuator driver co-located with physical simulator; subscribes to ev/actuator.

It shares the simulated hardware state with simulator.py, so there is only one
authoritative station. It does not make scheduling decisions.
"""
import json
import time


class Actuator:
    def __init__(self, station, run_id, lock, topic_prefix='ev'):
        self.station, self.run_id, self.lock = station, run_id, lock
        self.command_topic = topic_prefix + '/actuator'
        self.ack_topic = topic_prefix + '/ack'
        self.switch_count = 0
        self.rapid_switch_count = 0
        self.last_switch = {}

    def on_connect(self, client, userdata, flags, reason_code, properties):
        if reason_code == 0:
            client.subscribe(self.command_topic, qos=1)

    def on_message(self, client, userdata, msg):
        try:
            command = json.loads(msg.payload)
            if not isinstance(command, dict) or command.get('run_id') != self.run_id:
                return
            with self.lock:
                before = {e.charger:e.id for e in self.station.vehicles if e.charger and e.power_kw > 0}
                accepted = command.get('run_id') == self.run_id and self.station.accept(command)
                if accepted:
                    after = {e.charger:e.id for e in self.station.vehicles if e.charger and e.power_kw > 0}
                    for charger in self.station.chargers:
                        if before.get(charger) != after.get(charger):
                            now = self.station.hour
                            if charger in self.last_switch and now-self.last_switch[charger] < .1-1e-8:
                                self.rapid_switch_count += 1
                            self.last_switch[charger] = now
                            self.switch_count += 1
            client.publish(self.ack_topic,json.dumps({'run_id':self.run_id,'sequence':command.get('sequence'),
                'accepted':accepted, 'received_at':time.time(),
                'response_ms':max(0,(time.time()-command['sensor_timestamp'])*1000),
                'inference_ms':command.get('inference_ms'),
                'decision_ms':command.get('decision_ms'),
                'switch_count':self.switch_count,'rapid_switch_count':self.rapid_switch_count}),qos=1)
        except (ValueError, KeyError, TypeError) as exc:
            print('Rejected actuator message:',exc,flush=True)


if __name__ == '__main__':
    raise SystemExit('Actuator is attached to the sensor/plant process. Run python simulator.py.')

# Two laptops through the public EMQX broker

## Ready-to-run configuration

The project is configured for **broker.emqx.io:8883**, using verified TLS and no
username/password. Only the broker is hosted on the internet; the project laptop
still runs Node-RED, SQLite, ML and the dashboard.

```text
Sensor laptop -> public EMQX broker -> project laptop
Sensor laptop <- public EMQX broker <- control commands
```

The shared `mqtt-public.json` selects these topics:

- `gridsense/team3/b7749f4efd894610/telemetry`
- `gridsense/team3/b7749f4efd894610/actuator`
- `gridsense/team3/b7749f4efd894610/ack`

Both laptops must have the same copy of that file. Unique topics reduce collisions;
they are not private or authenticated. Other public-broker users can read messages
or publish to these topics. Use synthetic data only. TLS verifies the server and
encrypts transport; it does not restrict other clients' topic access. See the
[official public broker information](https://www.emqx.com/en/mqtt/public-mqtt5-broker).

## Project laptop (Windows)

Install dependencies using README if not already installed. Stop the previous
launcher, then run from the project folder:

```powershell
./start.ps1 -PublicBroker
```

This automatically generates `node-red/flows.public.json` with TLS, the broker
address, a unique client ID and the shared topics, then starts Node-RED and the
Python database/decision service. No local broker or sensor is started. No manual
Node-RED broker editing, cloud account or MQTT credentials are needed.

Open `http://127.0.0.1:1880/dashboard/station` for the dashboard and
`http://127.0.0.1:1880` for the editor. Keep this launcher running.

## Sensor laptop

Copy these **five current files** into one folder:

1. `simulator.py`
2. `actuator.py`
3. `station_core.py`
4. `tariff.py`
5. `mqtt-public.json`

Install Python 3.10+ and run in that folder:

```bash
python -m pip install "paho-mqtt>=2.1,<3"
python simulator.py --public-broker
```

Use `python3` if required by your OS. Add `--tou-demo` for the evening tariff demo.
The simulator prints the broker and topics when connected. Public mode does not
send private MQTT credentials even if MQTT_USERNAME/MQTT_PASSWORD are set.

Both laptops need internet access; they do not need the same Wi-Fi. No inbound
MQTT port or router port forwarding is required. Keep both clocks synchronized
for meaningful response-time measurements. Only run one live simulator for this
station. Stop the simulator and project launcher with Ctrl+C when finished.

## Verify the demonstration

2. Dashboard readings should update from the other laptop.
3. Accepted messages in the acknowledgement debug output confirm that decisions
   returned through MQTT and were applied by the sensor laptop.

The project has already passed a real-broker integration test using local test
clients connected through `broker.emqx.io`, not a local broker. It verified five

## History and model training

With the public-mode project launcher running, use this command on either laptop:

```bash
python simulator.py --public-broker --history
```

On the project laptop, wait until `http://127.0.0.1:8765/health` reports 1,008 history

## Other modes and troubleshooting

- `./start.ps1` keeps the original single-laptop local demo.
- `./start.ps1 -RemoteSensor` uses a local LAN broker as described in README.
- `./start.ps1 -CloudBroker` is for a private hosted broker configured manually in
  the original Node-RED flow; it does not select the public profile.
- Generated public-flow edits are replaced at startup. Make shared application
  changes in `node-red/flows.json` or the public-flow generator.

- A private broker can use `python simulator.py --broker-host HOST --tls --username USER`;

If another team uses this submission independently, choose a different unique

"""Performance-gated forecast plus dwell time and power deadband."""
import json
import math
import pickle
import time
from pathlib import Path
from station_core import schedule, site_limit_kw, edf_key
from tou_scheduler import apply_tou
from station_store import DB, database, read_state

_cache = {}


def load_bundle(path):
    path = Path(path).resolve()
    key = str(path)
    if key not in _cache:
        # Only load locally trained, trusted artifacts; pickle is not a data interchange format.
        bundle = pickle.loads(path.read_bytes()) if path.exists() else None
        if bundle:
            from ml_train import predict
            predict(bundle, 0)  # Warm imports, transforms and model before serving traffic.
        _cache[key] = bundle
    return _cache[key]


def initialize_models():
    """Call before binding HTTP port. New artifacts require a service restart."""
    return load_bundle(Path(__file__).with_name('artifacts')/'bundle.pkl')


def stabilize(state, plan, previous):
    """Hold valid occupants for >=6 simulated minutes; safety events may override.

    Preserve a socket for a continuing EV even after dwell expires. Rates within
    0.25 kW of the previous plan are held unless capacity/target changes demand it.
    """
    previous = previous or {}
    now = state['hour']
    active = {e['id']:e for e in state['vehicles'] if e['arrival'] <= now < e['departure'] and e['remaining_kwh'] > 1e-8}
    previous_assignments = {a['ev_id']:a for a in previous.get('assignments',[])}
    since = previous.get('assigned_since',{})
    chosen = []
    for a in previous.get('assignments',[]):
        if a['ev_id'] in active and now-since.get(a['ev_id'],now) < .1-1e-9:
            chosen.append(a['ev_id'])
    for a in plan['assignments']:
        if a['ev_id'] not in chosen and len(chosen) < len(state['chargers']):
            chosen.append(a['ev_id'])
    chosen.sort(key=lambda eid: edf_key(active[eid], now))
    # Existing assignments keep their physical socket; fill vacancies afterwards.
    sockets = {eid:previous_assignments[eid]['charger_id'] for eid in chosen if eid in previous_assignments}
    free = [c for c in state['chargers'] if c not in sockets.values()]
    for eid in chosen:
        if eid not in sockets:
            sockets[eid] = free.pop(0)
    remaining = max(0,site_limit_kw(state)-state['base_kw'])
    assignments = []
    for eid in chosen:
        ev = active[eid]
        desired = min(ev['max_kw'], remaining)
        old = previous_assignments.get(eid,{}).get('rate_kw')
        if old is not None and abs(desired-old) < .25:
            desired = old
        rate = math.floor(max(0,min(desired,ev['max_kw'],remaining))*100)/100
        remaining -= rate
        assignments.append({'ev_id':eid,'charger_id':sockets[eid],'rate_kw':rate})
    # No redistribution after deadband: that used to undo held power rates.
    plan['assignments'] = assignments
    plan['assigned_since'] = {eid:since.get(eid,now) if eid in previous_assignments else now for eid in chosen}
    plan['stability_policy'] = {'minimum_dwell_sim_minutes':6,'rate_deadband_kw':.25,
                               'override':'completion, departure and electrical safety'}
    return plan


def decide(key, path=DB, bundle_path=None, tou_enabled=True):
    started = time.perf_counter()
    state = read_state(key,path)  # No runtime sensor stream is used as a training input.
    bundle_path = bundle_path or Path(__file__).with_name('artifacts')/'bundle.pkl'
    bundle = load_bundle(bundle_path)
    if bundle:
        from ml_train import predict
        forecast, latency = predict(bundle,state['hour'])
        baseline = bundle['baseline']
        evaluation = bundle['report']
        selection = evaluation['selected_model']
    else:
        forecast, baseline, latency = 0,0,0
        evaluation = {'models':{},'selected_model':'untrained_safe_rules'}
        selection = 'untrained_safe_rules'
    # Existing scheduler reads a profile; replace ONLY the next-hour forecast.
    profile = [baseline]*24
    profile[int(state['hour']+1)%24] = forecast
    plan = schedule(state,{'profile_kwh':profile})
    plan.update(model=selection,performance=evaluation,inference_ms=latency,
                forecast_next_hour_kwh=forecast,run_id=state['run_id'],sensor_timestamp=state.get('timestamp',0))
    if not bundle:
        plan['alerts'].append('Models not trained: using safe deadline rules. Replay history and run ml_train.py.')
    with database(path) as conn:
        row = conn.execute('SELECT decision FROM cycles WHERE run_id=? AND sequence<? AND decision IS NOT NULL ORDER BY sequence DESC LIMIT 1',
                           (key['run_id'],key['sequence'])).fetchone()
        previous = json.loads(row['decision']) if row else None
    plan = apply_tou(state, plan, previous, enabled=tou_enabled)
    # The legacy stabilizer reallocates full available power, undoing price deferral.
    # Use it only for the fallback policy; certified ToU rates must remain intact.
    if plan['tou_status'] in ('disabled', 'fallback_edf'):
        plan = stabilize(state,plan,previous)
    plan['decision_ms'] = (time.perf_counter()-started)*1000
    with database(path) as conn:
        conn.execute('UPDATE cycles SET decision=? WHERE run_id=? AND sequence=?',(json.dumps(plan),key['run_id'],key['sequence']))
    return {'state':state,'decision':plan}

"""Repeatable full-scenario closed-loop comparison (simulated, not network timing)."""
import json
import pickle
import time
from pathlib import Path
from station_core import Station, schedule
from decision_engine import stabilize
from ml_train import ARTIFACTS, predict


def evaluate(feasible=False):
    bundle=pickle.loads((ARTIFACTS/'bundle.pkl').read_bytes())
    results={}
    for name in ['constant_baseline',*bundle['report']['models']]:
        model=None if name=='constant_baseline' else pickle.loads((ARTIFACTS/f'{name}.pkl').read_bytes())
        current={**bundle,'model':model}
        station=Station()
        if feasible:
            for ev in station.vehicles:
                ev.target = min(ev.target, ev.soc+.05)
        previous=None
        switches=rapid=violations=0
        last_mapping={}
        last_switch={}
        peak=0
        latencies=[]
        for _ in range(185):
            state=station.snapshot()
            start=time.perf_counter()
            forecast,_=predict(current,state['hour'])
            profile=[bundle['baseline']]*24
            profile[int(state['hour']+1)%24]=forecast
            plan=stabilize(state,schedule(state,{'profile_kwh':profile}),previous)
            assert station.accept(plan)
            latencies.append((time.perf_counter()-start)*1000)
            mapping={a['charger_id']:a['ev_id'] for a in plan['assignments'] if a['rate_kw']>0}
            for charger in station.chargers:
                if last_mapping.get(charger)!=mapping.get(charger):
                    switches+=1
                    if charger in last_switch and station.hour-last_switch[charger]<.1-1e-8:
                        rapid+=1
                    last_switch[charger]=station.hour
            last_mapping=mapping
            previous=plan
            station.step(1/30)
            observed=station.snapshot()
            peak=max(peak,observed['load_kw'])
            violations+=int(observed['load_kw']>observed['capacity_kw']+1e-6)
        required=sum(e.delivered_kwh+e.remaining for e in station.vehicles)
        results[name]={'deadline_success_fraction':sum(e.remaining<=.01 for e in station.vehicles)/len(station.vehicles),
                       'energy_fulfillment_fraction':sum(e.delivered_kwh for e in station.vehicles)/required,
                       'unmet_energy_kwh':sum(e.remaining for e in station.vehicles),
                       'peak_site_kw':peak,'capacity_violation_samples':violations,
                       'socket_switches':switches,'rapid_switches':rapid,
                       'mean_local_decision_ms':sum(latencies)/len(latencies)}
    report={'scenario':'feasible low-energy requests' if feasible else 'congested original requests',
            'definition':'Same six-EV scenario and initial state for each model; 185 steps; timing excludes MQTT/Node-RED. Full network timing is in live_check.json.',
            'results':results}
    filename = 'control_feasible.json' if feasible else 'control_comparison.json'
    (ARTIFACTS/filename).write_text(json.dumps(report,indent=2))
    return report


if __name__=='__main__':
    print(json.dumps(evaluate(),indent=2))
    print(json.dumps(evaluate(feasible=True),indent=2))

"""Paired deterministic tariff demo; no MQTT publications or production DB writes."""
import json
from pathlib import Path
from station_core import schedule, tou_demo_station
from tou_scheduler import apply_tou, CONTROL_HOURS
from tariff import price_at


def evaluate():
    results = {}
    for policy in ('unmanaged', 'edf', 'tou'):
        station = tou_demo_station(unmanaged=policy == 'unmanaged')
        previous = None
        cost = energy = peak = 0.
        fallback = 0
        samples = []
        for step in range(240):
            station.hour = 16 + step * CONTROL_HOURS  # Avoid accumulated clock roundoff.
            state = station.snapshot()
            plan = schedule(state, {'profile_kwh': [0.] * 24})
            if policy == 'tou':
                plan = apply_tou(state, plan, previous)
                fallback += plan['tou_status'] == 'fallback_edf'
            if not station.accept(plan):
                raise AssertionError('Actuator rejected demo plan')
            before = sum(e.delivered_kwh for e in station.vehicles)
            station.step(CONTROL_HOURS)
            delivered = sum(e.delivered_kwh for e in station.vehicles) - before
            price = price_at(state['hour'])
            cost += delivered * price
            energy += delivered
            load = station.base_kw + delivered / CONTROL_HOURS

# GridSense: Smart EV Charging and Load Management

Team 3 - Submission report

## Objective

Demonstrate a complete distributed IoT feedback loop for a simulated EV charging
station: sensor observations, MQTT transport, live visualization, persistent data,
evaluated machine learning, control decisions and actuator acknowledgements.

## Architecture and deployment

The supplied architecture image is `refererncesss.png`. One laptop runs the Python
sensor/plant simulator and attached actuator; the second runs Aedes on TCP 1883,
Node-RED, SQLite, the analytics/decision service and the dashboard. This describes
the retained local/LAN mode. The current public-broker mode instead connects both
laptops to `broker.emqx.io:8883` over verified TLS, using the shared prefix in
`mqtt-public.json`. No local MQTT broker is started in public mode.

1. `simulator.py` publishes JSON observations on `ev/telemetry` every two seconds.
2. Node-RED receives observations through MQTT with QoS 1.
3. Independent branches update the dashboard and POST observations to `/store`.
4. SQLite commits the observation and returns its run/sequence key. `/decide` reads
   the committed row, performs inference and builds a control plan.
5. Node-RED publishes that plan on `ev/actuator` through the same broker.
6. The sensor laptop validates and applies the plan and publishes `ev/ack`.
7. Node-RED stores acknowledgements for closed-loop evaluation. Subsequent readings
   reflect the action applied to the simulated plant.

The Python HTTP adapter is internal to the project laptop. MQTT connects the two
laptops; neither the dashboard nor database needs to be exposed to the LAN. The
live display continues independently when analytics is unavailable. The plant
rejects invalid, duplicate or out-of-order plans and expires stale commands.

## Simulation and scheduling

The station has six EVs, two charger sockets, a 10 kW rated supply and 1 kW base
load. A 5% reserve produces a 9.5 kW operating limit. Arrivals, departure deadlines,
remaining energy, battery state and charge-rate limits constrain scheduling.
The fallback scheduler uses feasibility-aware earliest departure priority, stable
socket assignments, dwell time and a power deadband. The tariff scheduler uses
constrained optimization to defer flexible demand while respecting deadlines;
solver failure falls back to deadline scheduling. Tariffs are illustrative INR/kWh.

The `--tou-demo` scenario provides feasible evening requests. The default congested
scenario deliberately includes demand that cannot all be served by its deadlines.

## Machine learning and evaluation

History replay sends 1,008 synthetic hourly records (42 days) through MQTT and
Node-RED to SQLite. Training selects database rows only. The chronological split
uses 28 training days, seven validation days and seven test days.

Five model families cover the three categories in the diagram:

- Traditional: decision tree and support vector regression/classification.
- Ensemble: random forest and XGBoost.
- Neural network: feed-forward ANN with hidden layers 64, 32 and 16.

Each family includes an energy regressor and an independently trained classifier
for high demand (at least 30 kWh per hour). Regression metrics are RMSE, MAE and R2;
classification metrics include accuracy, precision, recall and F1. Computational
metrics include training time, warmed inference latency, serialized size and peak
Python-tracked allocations. Tracked memory is not total process/GPU memory.

Selection uses validation RMSE subject to a 100 ms p95 inference limit and improvement

Classification: independently trained high-demand alarm, energy >= 30 kWh.

THRESHOLD_KWH = 30.0


def features(day, hour):
    # Calendar features are known BEFORE the forecast hour starts.
    return [hour, np.sin(2*np.pi*hour/24), np.cos(2*np.pi*hour/24), day % 7]


def scores(y, pred, probabilities=None):
    actual_class = y >= THRESHOLD_KWH
    predicted_class = pred >= THRESHOLD_KWH if probabilities is None else probabilities >= .5
    return {'accuracy': float(accuracy_score(actual_class, predicted_class)),
            'precision': float(precision_score(actual_class, predicted_class, zero_division=0)),
            'recall': float(recall_score(actual_class, predicted_class, zero_division=0)),
            'f1': float(f1_score(actual_class, predicted_class, zero_division=0)),
            'balanced_accuracy': float(balanced_accuracy_score(actual_class,predicted_class)),
            'confusion_matrix_tn_fp_fn_tp': confusion_matrix(actual_class,predicted_class,labels=[False,True]).ravel().tolist(),
            'average_precision': float(average_precision_score(actual_class,probabilities if probabilities is not None else pred)),
            'rmse_kwh': float(np.sqrt(mean_squared_error(y, pred))),
            'mae_kwh': float(mean_absolute_error(y, pred)), 'r2': float(r2_score(y, pred)),
            'positive_samples': int(actual_class.sum()), 'negative_samples':int((~actual_class).sum()),
            'majority_baseline_accuracy':float(max(actual_class.mean(),1-actual_class.mean())),
            'samples': len(y)}


def train(db=DB, output=ARTIFACTS, dataset='synthetic-history-v5'):
    with database(db) as conn:
        rows = conn.execute('SELECT day,hour,energy_kwh,source FROM demand_samples WHERE dataset=? ORDER BY day,hour', (dataset,)).fetchall()
    days = sorted({r['day'] for r in rows})
    if len(days) < 18 or any(sum(r['day'] == d for r in rows) != 24 for d in days):
        raise ValueError('Need at least 18 complete days in SQLite. Run simulator.py --history through Node-RED first.')
    first, second = len(days)*2//3, len(days)*5//6
    groups = [set(days[:first]), set(days[first:second]), set(days[second:])]
    splits = []
    for group in groups:
        subset = [r for r in rows if r['day'] in group]
        splits.append((np.array([features(r['day'],r['hour']) for r in subset]),
                       np.array([r['energy_kwh'] for r in subset])))
    (x,y),(xv,yv),(xt,yt) = splits
    for label, values in [('train',y),('validation',yv),('test',yt)]:
        if len(np.unique(values >= THRESHOLD_KWH)) != 2:
            raise ValueError(f'{label} must contain both demand classes; collect more representative data')
    from xgboost import XGBRegressor, XGBClassifier
    boost_options = dict(n_estimators=120, max_depth=3, learning_rate=.05,
                         subsample=.9, colsample_bytree=1., tree_method='hist',
                         n_jobs=1, random_state=42)
    models = {

            transformer=StandardScaler()),
        'traditional_svr': TransformedTargetRegressor(
            regressor=make_pipeline(StandardScaler(), SVR(C=10., epsilon=.1, kernel='rbf')),
            transformer=StandardScaler()),
        'ensemble_xgboost': XGBRegressor(objective='reg:squarederror', **boost_options)}
    classifiers = {
        'traditional_decision_tree':DecisionTreeClassifier(max_depth=6,min_samples_leaf=8,class_weight='balanced',random_state=42),
        'ensemble_random_forest':RandomForestClassifier(n_estimators=80,max_depth=8,min_samples_leaf=4,class_weight='balanced_subsample',n_jobs=1,random_state=42),
        'deep_ann':make_pipeline(StandardScaler(),MLPClassifier(hidden_layer_sizes=(64,32,16),

            else:
                classifier.fit(x,yc)
        training_time = time.perf_counter()-start
        _, peak = tracemalloc.get_traced_memory()
        tracemalloc.stop()

        model.predict(xv[:1])

            start = time.perf_counter()
            model.predict(xv[i % len(xv):i % len(xv)+1])
            timings.append((time.perf_counter()-start)*1000)

        test_probabilities[name]=pt
        comparisons[name] = {'validation': scores(yv, np.maximum(0,model.predict(xv)),pv),
            'test': scores(yt,np.maximum(0,model.predict(xt)),pt),
            'thresholded_regression_test': scores(yt,np.maximum(0,model.predict(xt))),
            'computational': {'training_seconds': training_time,

                'peak_traced_memory_bytes': peak, 'model_size_bytes': len(blob)+len(classifier_blob),
                'regressor_size_bytes':len(blob),'classifier_size_bytes':len(classifier_blob),
                'measurement_scope':'Training/memory/size include regressor + classifier. Control inference measures regressor only.'},
            'warnings': [str(w.message) for w in caught]}
    baseline = float(np.mean(y))
    baseline_val = scores(yv, np.full_like(yv,baseline))
    eligible = [n for n,m in comparisons.items() if m['computational']['inference_p95_ms'] <= 100
                and m['validation']['rmse_kwh'] <= baseline_val['rmse_kwh']]

    report = {'created_at':time.time(), 'dataset':dataset, 'source': sorted({r['source'] for r in rows}),

              'imbalance_handling':'Balanced tree/forest/SVC weights; XGBoost training-only class ratio; ANN training-only oversampling; validation/test unchanged.',
              'test_binary_disagreements':{a:{b:int(np.count_nonzero((pa>=.5)!=(pb>=.5))) for b,pb in test_probabilities.items()} for a,pa in test_probabilities.items()},
              'memory_definition':'Peak tracemalloc-tracked allocations during fit, not total process RSS or GPU memory',
              'selection_rule':'Lowest validation RMSE among models beating constant baseline and p95 inference <=100ms; test set never selects model',
              'models':comparisons, 'baseline_validation':baseline_val,
              'baseline_test':scores(yt,np.full_like(yt,baseline)), 'selected_model':selected}

def configure_connection(client, args):
    if args.ca_cert and not args.tls:
        raise ValueError('--ca-cert requires --tls')
    if args.username and not args.tls:
        raise ValueError('Use --tls when sending MQTT login credentials')
    if args.tls:
        client.tls_set_context(ssl.create_default_context(cafile=args.ca_cert))
    if args.username:
        password = os.environ.get('MQTT_PASSWORD')
        if password is None:
            password = getpass.getpass('MQTT password: ')
        client.username_pw_set(args.username, password)

"""Deterministic EV station, deadline scheduler and demand analytics (no I/O)."""
import math
import random
from dataclasses import dataclass, asdict

SAFETY_FACTOR = 0.95


def site_limit_kw(state):
    """Rated site capacity remains visible; 5% is reserved from all EV plans."""
    return max(0.0, state['capacity_kw'] * SAFETY_FACTOR)


def edf_key(ev, now):
    # Do not let an already impossible request starve a still-feasible deadline.
    impossible = ev['remaining_kwh'] > max(0, ev['departure']-now)*ev['max_kw'] + 1e-6
    return (impossible, ev['departure'], ev['arrival'], ev['id'])


@dataclass
class Vehicle:
    id: str
    arrival: float
    departure: float
    capacity: float
    soc: float
    target: float
    max_kw: float = 7.0
    charger: str | None = None
    status: str = "scheduled"
    power_kw: float = 0.0
    delivered_kwh: float = 0.0

    @property
    def remaining(self):
        return max(0.0, (self.target - self.soc) * self.capacity)


def demo_vehicles():
    # Explicitly synthetic; more vehicles than sockets demonstrates queuing.
    return [Vehicle("EV1", 0, 3, 40, .40, .70),
            Vehicle("EV2", 0, 2, 40, .50, .90),
            Vehicle("EV3", .25, 4, 50, .40, .65),
            Vehicle("EV4", .5, 2.5, 30, .60, .80),
            Vehicle("EV5", 1, 5, 60, .50, .70),
            Vehicle("EV6", 2, 6, 40, .30, .60)]


class Station:
    def __init__(self, vehicles=None, chargers=2, capacity_kw=10.0):
        self.vehicles = demo_vehicles() if vehicles is None else vehicles
        self.chargers = [f"C{i+1}" for i in range(chargers)]
        self.capacity_kw = capacity_kw
        self.base_kw = 1.0
        self.hour = 0.0
        self.sequence = 0
        self.command_sequence = -1
        self.command = {}
        self.command_until = -1.0
        self.last_applied_sequence = -1
        self.refresh()

    def refresh(self):
        for ev in self.vehicles:
            if self.hour >= ev.departure:
                ev.status = "departed"
                ev.charger = None
                ev.power_kw = 0
            elif ev.remaining < 1e-8:
                ev.status = "complete"
                ev.charger = None
                ev.power_kw = 0
            elif self.hour >= ev.arrival and ev.charger is None:
                ev.status = "queued"

    def snapshot(self):
        self.refresh()
        rows = []
        for ev in self.vehicles:
            row = asdict(ev)
            row["remaining_kwh"] = round(ev.remaining, 6)
            rows.append(row)
        return {"sequence": self.sequence, "hour": self.hour,
                "capacity_kw": self.capacity_kw, "base_kw": self.base_kw,
                "operating_limit_kw": self.capacity_kw * SAFETY_FACTOR,
                "chargers": self.chargers, "vehicles": rows,
                "load_kw": self.base_kw + sum(e.power_kw for e in self.vehicles),
                "applied_sequence": self.last_applied_sequence,
                "source": "synthetic_python_simulator"}

    def accept(self, command):
        # A whole-station plan is validated before any actuator state changes.
        seq = command["sequence"]
        if not isinstance(seq, int) or seq <= self.command_sequence or seq != self.sequence:
            return False
        assignments = command["assignments"]
        seen_ev, seen_charger = set(), set()
        total = 0.0
        by_id = {e.id: e for e in self.vehicles}
        for a in assignments:
            ev = by_id.get(a["ev_id"])
            rate = float(a["rate_kw"])
            if (ev is None or a["charger_id"] not in self.chargers
                    or ev.id in seen_ev or a["charger_id"] in seen_charger
                    or not math.isfinite(rate) or rate < 0 or rate > ev.max_kw
                    or not ev.arrival <= self.hour < ev.departure or ev.remaining <= 0):
                return False
            seen_ev.add(ev.id)
            seen_charger.add(a["charger_id"])
            total += rate
        if total > max(0, self.capacity_kw * SAFETY_FACTOR - self.base_kw) + 1e-9:
            return False
        self.command = {a["ev_id"]: dict(a) for a in assignments}
        self.command_sequence = seq
        self.last_applied_sequence = seq
        self.command_until = self.hour + 0.1
        for ev in self.vehicles:
            a = self.command.get(ev.id)
            ev.charger = a["charger_id"] if a else None
            ev.power_kw = a["rate_kw"] if a else 0.0
            if a:
                ev.status = "charging" if ev.power_kw > 0 else "connected"
        self.refresh()
        return True

    def step(self, hours):
        if not math.isfinite(hours) or hours <= 0:
            raise ValueError("hours must be positive and finite")
        # Clamp locally even if supply changes after a command was accepted.
        total = sum(a["rate_kw"] for a in self.command.values())
        scale = min(1, max(0, self.capacity_kw*SAFETY_FACTOR-self.base_kw) / total) if total else 0
        for ev in self.vehicles:
            a = self.command.get(ev.id)
            duration = max(0, min(hours, ev.departure-self.hour,
                                  self.command_until-self.hour))
            if a and duration > 0 and ev.arrival <= self.hour and ev.remaining > 0:
                taper = min(1, max(0, (1-ev.soc)/.2))
                power = min(ev.max_kw, a["rate_kw"]) * scale * taper
                energy = min(ev.remaining, power * duration)
                ev.soc += energy / ev.capacity
                ev.delivered_kwh += energy
                ev.power_kw = energy / hours
            else:
                ev.power_kw = 0
            if ev.charger is not None:
                ev.status = "charging" if ev.power_kw > 0 else "connected"
        self.hour += hours
        self.sequence += 1
        self.refresh()


def tou_demo_station(unmanaged=False):
    """Feasible peak-to-off-peak scenario; separate from the overloaded original demo."""
    station = Station([
        Vehicle('EV1', 16, 18, 40, .3, .4),
        Vehicle('EV2', 16, 24, 40, .3, .6),
    ], capacity_kw=100 if unmanaged else 10)
    station.hour = 16.
    return station


def historical_sessions(days=28, seed=42):
    """Independent synthetic training days with morning/evening arrival peaks."""
    rng = random.Random(seed)
    rows = []
    for day in range(days):
        for hour in range(24):
            count = max(0, round((4 if hour in (8, 9, 17, 18) else 1) + rng.gauss(0, 1)))
            for _ in range(count):
                rows.append({"day": day, "hour": hour,
                             "energy_kwh": rng.uniform(5, 20)})
    return rows


def demand_model():
    """Hourly seasonal-mean regression, evaluated on held-out whole days."""
    rows = historical_sessions()
    bins = [[0.0]*24 for _ in range(28)]
    counts = [0]*24
    for r in rows:
        bins[r["day"]][r["hour"]] += r["energy_kwh"]
        counts[r["hour"]] += 1
    profile = [sum(d[h] for d in bins[:21])/21 for h in range(24)]
    baseline = sum(profile)/24
    errors = [abs(day[h]-profile[h]) for day in bins[21:] for h in range(24)]
    naive = [abs(day[h]-baseline) for day in bins[21:] for h in range(24)]
    return {"profile_kwh": profile, "arrivals_per_hour": [n/28 for n in counts],
            "mae_kwh": sum(errors)/len(errors), "baseline_mae_kwh": sum(naive)/len(naive),
            "training_days": 21, "test_days": 7,
            "source": "seeded synthetic history; not a real-world accuracy claim"}


def schedule(state, model=None):
    model = demand_model() if model is None else model
    now = state["hour"]
    active = [e for e in state["vehicles"]
              if e["arrival"] <= now < e["departure"] and e["remaining_kwh"] > 1e-8]
    active.sort(key=lambda e: edf_key(e, now))
    available = max(0.0, site_limit_kw(state)-state["base_kw"])
    forecast = model["profile_kwh"][int(now+1) % 24]
    typical = sum(model["profile_kwh"])/24
    # Forecasted busy periods cause feasible sessions to charge earlier.
    reserve_factor = 1.25 if forecast > typical else 1.0
    assignments, alerts = [], []
    for e in active:
        if e["remaining_kwh"] > (e["departure"]-now)*e["max_kw"] + 1e-6:
            alerts.append(f'{e["id"]}: cannot meet target before departure at maximum rate')
    for deadline in sorted({e["departure"] for e in active}):
        needed = sum(e["remaining_kwh"] for e in active if e["departure"] <= deadline)
        if needed > available*(deadline-now) + 1e-6:
            alerts.append("Shared supply cannot meet all current deadlines")
            break
    for charger, e in zip(state["chargers"], active):
        # Work-conserving EDF: finish the first feasible deadline before
        # spreading scarce power across later requests.
        rate = min(e["max_kw"], available)
        rate = math.floor(max(0, rate)*100)/100
        available -= rate
        assignments.append({"charger_id": charger, "ev_id": e["id"], "rate_kw": rate})
    for e in state["vehicles"]:
        if e["status"] == "departed" and e["remaining_kwh"] > .01:
            alerts.append(f'{e["id"]}: departed with {e["remaining_kwh"]:.2f} kWh unmet')
    return {"sequence": state["sequence"], "assignments": assignments,
            "alerts": alerts, "forecast_next_hour_kwh": forecast,
            "forecast_factor": reserve_factor, "analytics": model,
            "operating_limit_kw": site_limit_kw(state),
            "reason": "Feasibility-aware EDF; impossible requests get best effort; 5% site reserve"}

"""Node-RED HTTP persistence/evaluation boundary. Never publishes MQTT itself."""
import json
from http.server import BaseHTTPRequestHandler, HTTPServer
from station_store import DB, database, ingest
from decision_engine import decide, initialize_models


def closed_loop(run_id,path=DB):
    with database(path) as conn:
        states = [json.loads(r['telemetry']) for r in conn.execute('SELECT telemetry FROM cycles WHERE run_id=? ORDER BY sequence',(run_id,))]
        acks = [json.loads(r['payload']) for r in conn.execute('SELECT payload FROM actuator_acks WHERE run_id=?',(run_id,))]
    if not states:
        return {}
    last = states[-1]
    departed = [e for e in last['vehicles'] if e['status']=='departed']
    required = sum(e['delivered_kwh']+e['remaining_kwh'] for e in departed)
    latencies = sorted(a['response_ms'] for a in acks if a['accepted'])
    inference = [a['inference_ms'] for a in acks if a['accepted'] and a.get('inference_ms') is not None]
    decisions = [a['decision_ms'] for a in acks if a['accepted'] and a.get('decision_ms') is not None]
    return {'departed_vehicles':len(departed),
            'deadline_success_fraction':sum(e['remaining_kwh'] <= .01 for e in departed)/len(departed) if departed else None,
            'departed_energy_fulfillment_fraction':sum(e['delivered_kwh'] for e in departed)/required if required else None,
            'unmet_departure_kwh':sum(e['remaining_kwh'] for e in departed),
            'peak_site_kw':max(s['load_kw'] for s in states),
            'capacity_violation_samples':sum(s['load_kw'] > s['capacity_kw']+1e-6 for s in states),
            'operating_limit_kw':last['capacity_kw']*.95,
            'safety_margin_violation_samples':sum(s['load_kw'] > s['capacity_kw']*.95+1e-6 for s in states),
            'accepted_commands':len(latencies),'acknowledgements':len(acks),
            'response_mean_ms':sum(latencies)/len(latencies) if latencies else None,
            'response_p95_ms':latencies[min(len(latencies)-1,int(.95*len(latencies)))] if latencies else None,
            'mean_inference_ms':sum(inference)/len(inference) if inference else None,
            'mean_decision_ms':sum(decisions)/len(decisions) if decisions else None,
            'socket_switches':max((a.get('switch_count',0) for a in acks),default=0),
            'rapid_switches':max((a.get('rapid_switch_count',0) for a in acks),default=0)}


def process(payload,path=DB):
    key = ingest(payload,path)  # Separate committed transaction BEFORE decision/model input reads.
    if 'stored_history_rows' in key:
        return key
    result = decide(key,path)
    result['closed_loop'] = closed_loop(key['run_id'],path)
    return result


class Handler(BaseHTTPRequestHandler):
    def respond(self,data):
        body = json.dumps(data,allow_nan=False).encode()
        self.send_response(200)
        self.send_header('Content-Type','application/json')
        self.send_header('Content-Length',str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        if self.path != '/health':
            self.send_error(404)
            return
        with database() as conn:
            count = conn.execute('SELECT count(*) FROM demand_samples').fetchone()[0]
        self.respond({'status':'ok','history_rows':count})

    def do_POST(self):
        try:
            size = int(self.headers.get('Content-Length',0))
            if not 0 < size <= 1000000:
                raise ValueError('Invalid request size')
            payload = json.loads(self.rfile.read(size))
            if self.path == '/store':
                self.respond(ingest(payload))
            elif self.path == '/decide':
                result = decide(payload)
                result['closed_loop'] = closed_loop(payload['run_id'])
                self.respond(result)
            elif self.path == '/cycle':
                self.respond(process(payload))
            elif self.path == '/ack':
                with database() as conn:
                    # Keep successful application evidence if QoS redelivery later gets rejected.
                    conn.execute('INSERT INTO actuator_acks VALUES (?,?,?) ON CONFLICT(run_id,sequence) DO UPDATE SET payload=excluded.payload WHERE json_extract(actuator_acks.payload,\'$.accepted\')=0',
                                 (payload['run_id'],payload['sequence'],json.dumps(payload)))
                self.respond({'stored':True})
            else:
                self.send_error(404)
        except (ValueError,KeyError,TypeError,ZeroDivisionError) as exc:
            self.send_error(400,str(exc))


if __name__ == '__main__':
    initialize_models()
    print('GridSense SQLite/decision service: http://127.0.0.1:8765',flush=True)
    HTTPServer(('127.0.0.1',8765),Handler).serve_forever()

"""SQLite boundary: ingest commits before any analytics reads."""
import json
import sqlite3
from contextlib import contextmanager
from pathlib import Path

DB = Path(__file__).with_name('station.db')


@contextmanager
def database(path=DB):
    conn = sqlite3.connect(path, timeout=15)
    conn.row_factory = sqlite3.Row
    try:
        conn.execute('PRAGMA journal_mode=WAL')
        conn.execute('CREATE TABLE IF NOT EXISTS demand_samples (dataset TEXT, day INTEGER, hour INTEGER, energy_kwh REAL, source TEXT, PRIMARY KEY(dataset,day,hour))')
        conn.execute('CREATE TABLE IF NOT EXISTS cycles (run_id TEXT, sequence INTEGER, hour REAL, telemetry TEXT, decision TEXT, PRIMARY KEY(run_id,sequence))')
        conn.execute('CREATE TABLE IF NOT EXISTS actuator_acks (run_id TEXT, sequence INTEGER, payload TEXT, PRIMARY KEY(run_id,sequence))')
        conn.execute('CREATE TABLE IF NOT EXISTS ml_evaluations (created_at REAL PRIMARY KEY, report TEXT)')
        yield conn
        conn.commit()
    except Exception:
        conn.rollback()
        raise
    finally:
        conn.close()


def ingest(payload, path=DB):
    with database(path) as conn:
        if payload.get('kind') == 'history':
            rows = payload['samples']
            if len(rows) > 5000:
                raise ValueError('Too many history samples')
            import math
            for r in rows:
                if not (0 <= r['hour'] < 24 and r['day'] >= 0 and math.isfinite(r['energy_kwh']) and r['energy_kwh'] >= 0):
                    raise ValueError('Invalid history sample')
            conn.executemany('INSERT OR IGNORE INTO demand_samples VALUES (?,?,?,?,?)',
                             [(payload['dataset'], r['day'], r['hour'], r['energy_kwh'], payload['source']) for r in rows])
            return {'stored_history_rows': len(rows)}
        conn.execute('INSERT OR IGNORE INTO cycles VALUES (?,?,?,?,NULL)',
                     (payload['run_id'], payload['sequence'], payload['hour'], json.dumps(payload, allow_nan=False)))
    return {'run_id': payload['run_id'], 'sequence': payload['sequence']}


def read_state(key, path=DB):
    with database(path) as conn:
        row = conn.execute('SELECT telemetry FROM cycles WHERE run_id=? AND sequence=?',
                           (key['run_id'], key['sequence'])).fetchone()
        if not row:
            raise ValueError('Telemetry not committed to SQLite')
        return json.loads(row['telemetry'])

"""Illustrative tariff in INR/kWh; hours are absolute SIMULATION hours."""
import math

HOURLY_PRICES = (3.,) * 6 + (6.,) * 10 + (12.,) * 6 + (3.,) * 2


def price_at(hour):
    if not math.isfinite(hour):
        raise ValueError('Simulation hour must be finite')
    return HOURLY_PRICES[math.floor(hour) % 24]


def telemetry_fields(state):
    active = [e for e in state['vehicles'] if e['arrival'] <= state['hour'] < e['departure']
              and e['remaining_kwh'] > 1e-8]
    # Demand envelope only: not a separate counterfactual simulation.
    demand = sum(sorted((e['max_kw'] for e in active), reverse=True)[:len(state['chargers'])])
    return {'price_per_kwh': price_at(state['hour']), 'price_currency': 'INR',
            'charging_load_kw': max(0., state['load_kw'] - state['base_kw']),
            'unmanaged_demand_estimate_kw': state['base_kw'] + demand}

"""Receding-horizon cost minimization with hard energy/deadline/socket constraints.

Only the first control interval is applied. Replan from committed telemetry.
Infeasible requests or solver failures use the existing best-effort EDF plan.
"""
import math
import numpy as np
from scipy.optimize import Bounds, LinearConstraint, milp
from scipy.sparse import lil_matrix
from station_core import site_limit_kw
from tariff import price_at

CONTROL_HOURS = 1 / 30  # Must match simulator.py's two simulated minutes.


def apply_tou(state, plan, previous=None, enabled=True, time_limit=.5):
    now = state['hour']
    plan.update(price_per_kwh=price_at(now), price_currency='INR',
                tariff_profile=[price_at(h) for h in range(24)])
    if not enabled:
        plan['tou_status'] = 'disabled'
        return plan
    vehicles = [e for e in state['vehicles'] if e['departure'] > now
                and e['remaining_kwh'] > 1e-8]
    if not vehicles:
        plan.update(tou_status='idle', assignments=[])
        return plan
    available = max(0., site_limit_kw(state) - state['base_kw'])

    def fallback(reason):
        plan['tou_status'] = 'fallback_edf'
        plan['alerts'].append('ToU: ' + reason + '; using best-effort deadline scheduling')
        return plan

    # Conservative lower bound on taper efficiency until each vehicle's target.
    efficiency = [min(1., max(0., (1. - e['target']) / .2)) for e in vehicles]
    for e, eta in zip(vehicles, efficiency):
        if e['remaining_kwh'] > max(0., e['departure']-max(now, e['arrival'])) * min(e['max_kw'], available) * eta + 1e-6:
            return fallback('deadline feasibility cannot be certified (energy/rate/taper)')
    end = max(e['departure'] for e in vehicles)
    if end - now > 48 or len(vehicles) > 30:
        return fallback('planning horizon exceeds demo limits')
    # First interval matches the actuator cadence; later intervals <=15 minutes.
    first_end = min(now + CONTROL_HOURS, end)
    boundaries = {now, first_end, end}
    boundaries.update(t / 4 for t in range(math.ceil(first_end * 4), math.ceil(end * 4))
                      if first_end < t / 4 < end)
    for e in vehicles:
        boundaries.update(t for t in (e['arrival'], e['departure']) if first_end < t < end)
    edges = sorted(boundaries)
    durations = np.diff(edges)
    n, slots = len(vehicles), len(durations)
    count = n * slots
    # p[i,t] commanded kW and binary z[i,t] socket occupancy.
    upper = np.zeros(2 * count)
    objective = np.zeros(2 * count)
    for i, e in enumerate(vehicles):
        for t, duration in enumerate(durations):
            k = i * slots + t
            if e['arrival'] <= edges[t] + 1e-9 and edges[t+1] <= e['departure'] + 1e-9:
                upper[k], upper[count+k] = e['max_kw'], 1
            # Earlier charging wins equal-price ties. Physical load may taper below command.
            objective[k] = duration * (price_at(edges[t] + 1e-8) + 1e-4 * (edges[t]-now))
            objective[count+k] = 1e-7
    matrix = lil_matrix((n + 2 * slots + count, 2 * count))
    lower = np.full(matrix.shape[0], -np.inf)
    limit = np.zeros(matrix.shape[0])
    for i, e in enumerate(vehicles):
        matrix[i, i*slots:(i+1)*slots] = durations * efficiency[i]
        lower[i] = e['remaining_kwh']
        limit[i] = np.inf
    for t in range(slots):
        for i in range(n):
            k = i * slots + t
            matrix[n+t, k] = 1
            matrix[n+slots+t, count+k] = 1
        limit[n+t] = available
        limit[n+slots+t] = len(state['chargers'])
    for k in range(count):
        row = n + 2*slots + k
        matrix[row, k] = 1
        matrix[row, count+k] = -vehicles[k // slots]['max_kw']
    try:
        result = milp(objective, integrality=np.r_[np.zeros(count), np.ones(count)],
                      bounds=Bounds(np.zeros(2*count), upper),
                      constraints=LinearConstraint(matrix.tocsc(), lower, limit),
                      options={'time_limit': time_limit, 'mip_rel_gap': .001})
    except (ValueError, RuntimeError):
        return fallback('optimizer error')
    if result.x is None or not np.all(np.isfinite(result.x)):
        return fallback('no feasible plan returned within solver budget')
    # Validate even time-limited incumbents before relying on deadline feasibility.
    values = matrix @ result.x
    if (np.any(values < lower - 1e-6) or np.any(values > limit + 1e-6)
            or np.any(result.x < -1e-6) or np.any(result.x > upper + 1e-6)
            or np.any(abs(result.x[count:] - np.round(result.x[count:])) > 1e-6)):
        return fallback('solver result failed constraint validation')
    chosen = [(e, max(0., float(result.x[i*slots]))) for i, e in enumerate(vehicles)
              if result.x[i*slots] > 1e-7]
    if len(chosen) > len(state['chargers']):
        return fallback('invalid first-interval socket allocation')
    old = {a['ev_id']: a['charger_id'] for a in (previous or {}).get('assignments', [])}
    sockets = {e['id']: old[e['id']] for e, _ in chosen if old.get(e['id']) in state['chargers']}
    free = [c for c in state['chargers'] if c not in sockets.values()]
    assignments = []
    remaining = available
    for e, rate in chosen:
        # Only remove solver floating-point overshoot; do not round to 0.01 kW.
        rate = min(rate, remaining, e['max_kw'])
        remaining -= rate
        socket = sockets.get(e['id']) or free.pop(0)
        assignments.append({'ev_id': e['id'], 'charger_id': socket, 'rate_kw': rate})
    plan.update(assignments=assignments, tou_status='optimal' if result.success else 'feasible_time_limit',
                reason='Minimum tariff cost subject to known deadlines, site capacity and socket limits',
                planned_cost_upper_bound=float(np.dot(objective[:count], result.x[:count])),
                stability_policy={'override': 'ToU feasibility; preserve existing socket where possible'},
                assigned_since={e['id']: (previous or {}).get('assigned_since', {}).get(e['id'], now)
                                for e, _ in chosen})
    return plan

// Derive a public-broker flow without changing the local/private demo flow.
const fs = require('fs');
const path = require('path');
const crypto = require('crypto');

function buildPublicFlow(profile, base) {
  const prefix = profile.topic_prefix;
  if (typeof prefix !== 'string' || !prefix || /^[\/]|[\/]$|[+#\x00]/.test(prefix)) {
    throw new Error('Invalid MQTT topic prefix');
  }
  const flows = JSON.parse(JSON.stringify(base));
  const nodes = Object.fromEntries(flows.map(n => [n.id, n]));
  // New ID avoids inheriting any saved private-broker credentials.
  Object.assign(nodes.broker, {id: 'public-broker', name: 'EMQX public broker (TLS)',
    broker: profile.host, port: String(profile.port), usetls: true, tls: 'public-tls',
    clientid: 'gs_project_' + crypto.randomBytes(8).toString('hex')});
  delete nodes.broker.credentials;
  for (const node of flows) if (node.broker === 'broker') node.broker = 'public-broker';
  for (const [id, suffix] of [['sensor', 'telemetry'], ['actuator', 'actuator'], ['ack', 'ack']]) {
    nodes[id].topic = `${prefix}/${suffix}`;
  }
  flows.push({id: 'public-tls', type: 'tls-config', name: 'Verify EMQX certificate',
    cert: '', key: '', ca: '', certname: '', keyname: '', caname: '',
    servername: profile.host, verifyservercert: true, alpnprotocol: ''});
  nodes.station.label = 'GridSense public MQTT loop';
  nodes.station.info = `Public MQTT over verified TLS; topic prefix ${prefix}. Synthetic demo data only.`;
  return flows;
}

if (require.main === module) {
  const profile = JSON.parse(fs.readFileSync(path.join(__dirname, '../mqtt-public.json'), 'utf8'));
  const base = JSON.parse(fs.readFileSync(path.join(__dirname, 'flows.json'), 'utf8'));
  fs.writeFileSync(path.join(__dirname, 'flows.public.json'), JSON.stringify(buildPublicFlow(profile, base), null, 2));
  console.log(`Public MQTT: ${profile.host}:${profile.port}; topics ${profile.topic_prefix}/*`);
}
module.exports = {buildPublicFlow};

export default {
  data() { return {now:Date.now(),timer:null,search:'',filter:'all',filters:[{key:'all',label:'All sessions'},{key:'active',label:'On site'},{key:'queued',label:'Waiting'},{key:'complete',label:'Complete'},{key:'departed',label:'Departed'}]} },
  mounted() { this.timer=setInterval(()=>{this.now=Date.now()},1000) },
  unmounted() { clearInterval(this.timer) },
  computed: {
    state() { const p=this.msg?.payload; return Array.isArray(p?.vehicles) ? p : null },
    vehicles() { return this.state?.vehicles || [] },
    fresh() { const age=this.now-(this.state?.timestamp || 0)*1000; return !!this.state && age>=-5000 && age<10000 },
    lastSeen() { return Number.isFinite(this.state?.timestamp) ? new Date(this.state.timestamp*1000).toLocaleTimeString() : 'Not received' },
    charging() { return this.vehicles.filter(e=>e.status==='charging').length },
    queued() { return this.vehicles.filter(e=>e.status==='queued').length },
    completed() { return this.vehicles.filter(e=>e.status==='complete').length },
    gauge() {
      const kw=this.state?.load_kw;
      if(!Number.isFinite(kw) || kw<0) return {value:'—',percent:0,color:'#64748b',label:'Reading unavailable'};
      return {value:kw.toFixed(2),percent:Math.min(100,kw*10),
        color:kw<7?'#16a34a':kw<=9.5?'#eab308':'#dc2626',
        label:kw<7?'Normal load':kw<=9.5?'High load':kw<10?'Above operating limit':'At or above rated capacity'};
    },
    overLimit() { return this.state?.load_kw > this.state?.operating_limit_kw+1e-6 },
    tariffLabel() { const p=this.state?.price_per_kwh; return !Number.isFinite(p)?'Tariff unavailable':p<=3?'Off-peak rate':p>=12?'Peak rate':'Standard rate' },
    nextDeparture() { return this.vehicles.filter(e=>e.departure>this.state.hour && e.arrival<=this.state.hour && e.remaining_kwh>.01).sort((a,b)=>a.departure-b.departure)[0] },
    visibleVehicles() { return this.vehicles.filter(e=>e.id.toLowerCase().includes(this.search.toLowerCase()) && (this.filter==='all' || (this.filter==='active' ? e.arrival<=this.state.hour && this.state.hour<e.departure : e.status===this.filter))) }
  },
  methods: {
    fmt(value,digits=2) { return Number.isFinite(value)?value.toFixed(digits):'—' },
    simTime(hour) { if(!Number.isFinite(hour)) return '—'; const minutes=Math.floor(hour*60+1e-6); const day=Math.floor(minutes/1440); return (day?'Day '+(day+1)+' · ':'')+String(Math.floor(minutes/60)%24).padStart(2,'0')+':'+String(minutes%60).padStart(2,'0') },
    statusLabel(status) { return {scheduled:'Scheduled',queued:'Waiting',charging:'Charging',connected:'Connected',complete:'Target reached',departed:'Departed'}[status] || status }
  }
}

import sys

import paho.mqtt.client as mqtt

workers, handles, acks, states = [], [], [], []

def start(args, name, cwd=ROOT):
    handle = open(ROOT/f'{name}.log','w')
    handles.append(handle)
    process = subprocess.Popen(args,cwd=cwd,stdout=handle,stderr=subprocess.STDOUT)
    workers.append(process)
    return process


def wait_http(url, timeout=30):
    deadline = time.time()+timeout
    while time.time()<deadline:
        try:
            with urllib.request.urlopen(url,timeout=2) as response:
                return response.read()
        except OSError:
            time.sleep(.5)
    raise AssertionError('HTTP startup timed out: '+url)


def on_message(client, userdata, message):
    data = json.loads(message.payload)
    if message.topic=='ev/ack':
        acks.append(data)
    elif data.get('kind') != 'history':
        states.append(data)


try:
    start(['node','node-red/demo-broker.cjs'],'test-broker')
    service=start([sys.executable,'station_service.py'],'test-service')

    assert ack_count>0

    print(json.dumps(result,indent=2))
finally:

        if worker.poll() is None:
            worker.terminate()
            worker.wait(timeout=10)
    for handle in handles:
        handle.close()

"""Exercise the real public TLS broker with synthetic data and isolated test topics.

Uses existing trained models; writes test cycles to station.db, not training data.
Requires free local ports 1880/8765. Does not start a local broker.
"""
import json
import socket
import sqlite3
import ssl
import subprocess
import sys
import threading
import time
import urllib.request
import uuid
from pathlib import Path
import paho.mqtt.client as mqtt

ROOT = Path(__file__).resolve().parents[1]


def main():
    profile = json.loads((ROOT/'mqtt-public.json').read_text())
    prefix = profile['topic_prefix'] + '/check-' + uuid.uuid4().hex[:12]
    workers, handles, states, acks = [], [], [], []
    subscribed = threading.Event()
    client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2, client_id='gs_check_'+uuid.uuid4().hex[:12])
    client.tls_set_context(ssl.create_default_context())

    def start(args, name, cwd=ROOT):
        handle = open(ROOT/f'{name}.log', 'w')
        handles.append(handle)
        worker = subprocess.Popen(args, cwd=cwd, stdout=handle, stderr=subprocess.STDOUT,
                                  creationflags=getattr(subprocess, 'CREATE_NO_WINDOW', 0))
        workers.append(worker)

    def wait_http(url):
        deadline = time.monotonic()+40
        while time.monotonic() < deadline:
            if any(w.poll() is not None for w in workers):
                raise RuntimeError('Test service exited; inspect public-check-*.log')
            try:
                with urllib.request.urlopen(url, timeout=2) as response:
                    return response.status
            except OSError:
                time.sleep(.5)
        raise RuntimeError('Service startup timed out: '+url)

    def connected(c, userdata, flags, reason, properties):
        if reason == 0:
            c.subscribe([(prefix+'/telemetry', 1), (prefix+'/ack', 1)])

    def on_subscribe(c, userdata, mid, reasons, properties):
        if all(not reason.is_failure for reason in reasons):
            subscribed.set()

    def received(c, userdata, message):
        data = json.loads(message.payload)
        (acks if message.topic.endswith('/ack') else states).append(data)

    client.on_connect, client.on_subscribe, client.on_message = connected, on_subscribe, received
    try:
        for port in (1880, 8765):
            with socket.socket() as probe:
                probe.settimeout(1)
                if probe.connect_ex(('127.0.0.1', port)) == 0:
                    raise RuntimeError(f'Stop the existing project first; port {port} is busy')
        # This generated flow uses the actual app wiring and the test's isolated topics.
        subprocess.run(['node', '-e',
            "const fs=require('fs');const {buildPublicFlow}=require('./node-red/build-public-flow.cjs');"
            "const p=JSON.parse(fs.readFileSync('mqtt-public.json'));p.topic_prefix=process.argv[1];"
            "fs.writeFileSync('node-red/flows.public-check.json',JSON.stringify(buildPublicFlow(p,JSON.parse(fs.readFileSync('node-red/flows.json')))));",
            prefix], cwd=ROOT, check=True)
        client.connect(profile['host'], profile['port'], 60)
